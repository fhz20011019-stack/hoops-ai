⚙️ Dify Agent 配置

填写 Dify 应用的 API 地址与 Key。配置保存在本机浏览器 localStorage，仅用于直连 Dify，不会上传到其它地方。

Dify Cloud 用 https://api.dify.ai/v1；自部署换成你自己的域名，末尾带 /v1。
Dify 应用 → 访问 API → API 密钥（形如 app- 开头）。
若浏览器报 CORS / Failed to fetch，说明 Dify 未放行本站域名。两种解法：① 在 Dify 的 API_CORS_ALLOWED_ORIGINS 加入本页域名；② 填一个转发前缀，请求会变成 前缀 + 完整 Dify 地址。
若你的 Dify 应用定义了必填输入变量，在这里补齐；对话时每次都会带上。
安全提醒：这是纯静态页面，写进文件里的 Key 会被任何拿到链接的人看到。正式对外发布时建议：① 用面向终端用户的 Dify 账号 + 域名白名单；② 或把 Key 放在 Cloudflare Worker 之类的服务端中转里，页面只填中转地址。
